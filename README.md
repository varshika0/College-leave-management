# College Leave Management System

A web-based application that digitizes leave application and approval in colleges. Students apply for leave online, HODs and staff approve requests, and Admins manage users and reports.

## Key Feature: Duplicate Certificate Detector
When a student uploads a medical certificate or OD letter, the system creates a unique hash (fingerprint) of the file. If the same file is uploaded again, by the same or a different student, the HOD sees a "⚠ This document was already used" flag. This helps catch fake or reused certificates.

## Roles
- **Student:** Apply for leave, upload certificates, adjust academic load
- **HOD / Staff:** Review and approve or reject leave requests
- **Admin:** Manage HOD, staff, and student details and view leave reports

## Advantages
- **Paperless:** Removes manual forms and register entries
- **Time-saving:** Faster applications and approvals for everyone
- **Fraud prevention:** Duplicate certificate detection stops reused or fake documents
- **Transparency:** Students can track the status of every request
- **Accountability:** Every decision is recorded and traceable
- **Easy reporting:** Admins get leave reports in one place
